# 线性方程组求解器 - 设计文档

**日期:** 2026-06-11  
**状态:** 待审批

## 概述

一个移动端友好的单页面网页工具，用于求解 n 阶非齐次线性方程组。用户输入增广矩阵，系统通过高斯消元法求解，结果优先以分数表示。

## 功能范围

- **核心功能：** 解 n 阶非齐次线性方程组（增广矩阵输入 → 高斯消元 → 解向量输出）
- **暂不包含：** 矩阵加减乘除、行列式、特征值、RREF 等（后续按需添加）

## 技术选型

- **单文件 HTML**：HTML + CSS + JavaScript，零依赖，无框架
- **部署：** 直接打开即可使用，可部署到任何静态托管（GitHub Pages 等）

## 交互设计

### 输入流程

```
用户选择阶数 n → 填入增广矩阵各元素 → 点击"求解" → 查看结果
```

### 详细设计

| 项目 | 设计 |
|------|------|
| 矩阵阶数 | 下拉菜单，2~10 阶，默认 3 阶。切换阶数时清空所有已输入内容 |
| 增广矩阵输入 | n×(n+1) 文本网格，每个格子直接输入，最后一列（常数项）用背景色区分 |
| 输入格式 | 统一文本输入，支持整数 `2`、分数 `1/2`、小数 `0.5`，系统自动解析 |
| 结果展示 | 只显示最终解向量，不做步骤展示 |

### 结果表示规则（严格优先级）

1. **整数**：如 `2`、`-3`
2. **分数**（最简分数）：如 `1/2`、`-3/4`
3. **小数**：仅在分数无法表示时使用（极端情况），保留 6 位有效数字

### 特殊情况处理

| 情况 | 显示 |
|------|------|
| 唯一解 | `x₁ = 2, x₂ = 1/2, x₃ = -3` |
| 无解 | 明确提示"方程组无解" |
| 无穷多解 | 明确提示"方程组有无穷多解" |

## 核心算法

### 高斯消元（列主元选取）

1. 遍历列 k = 0..n-1：
   - 在列 k 中（从第 k 行向下）找绝对值最大的行作为主元
   - 若主元为 0 → 矩阵奇异（无解或无穷多解）
   - 交换当前行与主元行
   - 对第 k 行归一化（除以主元）
   - 消去下方所有行的第 k 列
2. 回代：从最后一行向上，依次求解每个变量

### 分数类（`Fraction`）

所有中间计算使用分数，避免浮点误差：

- 内部存储：`num`（分子）、`den`（分母），大整数用 `BigInt` 或直接 `number`
- 运算：加减乘除均在运算后立即约分（GCD）
- 显示：`den === 1` 时直接显示整数，否则显示 `num/den`

**简化处理：** 阶数上限 10，数值范围有限，使用 JavaScript `number` 配合 GCD 约分即可（若出现极大数再升级 BigInt）。

### 行列式判断

- 消元过程中若某列主元为 0（约分后分子为 0）→ 矩阵奇异
- 奇异时判断：比较 rank(A) 与 rank([A|b])
  - rank(A) < rank([A|b]) → 无解
  - rank(A) = rank([A|b]) < n → 无穷多解
