# 📐 线性方程组求解器

一个移动端友好的在线工具，用于求解 **n 阶非齐次线性方程组**。输入增广矩阵，通过高斯-约当消元法得出精确解。

## ✨ 特性

- **精确运算** — 全有理数（分数）运算，优先整数 → 分数 → 小数输出，无浮点误差
- **灵活输入** — 支持整数 `3`、分数 `1/2`、小数 `0.5` 混合输入
- **阶数可选** — 2~10 阶，下拉切换
- **移动优先** — 响应式设计，适配手机、平板、桌面
- **零依赖** — 纯 HTML + CSS + JavaScript，离线可用

## 🚀 使用

1. 打开 [在线页面](https://adfihasd.github.io/Counter/) 或本地 `index.html`
2. 选择矩阵阶数
3. 填入增广矩阵（最后一列为常数项）
4. 点击 **求解** 查看结果

## 📖 示例

求解方程组：
```
2x + 2y - z = 5
x - y + 2z = 3
3x + y - z = 2
```

输入增广矩阵：

|   |   |   |   |
|---|---|---|---|
| 2 | 2 | -1 | 5 |
| 1 | -1 | 2 | 3 |
| 3 | 1 | -1 | 2 |

结果：**x = 1/2, y = 7/2, z = 3**

## 🛠 技术

| 模块 | 说明 |
|------|------|
| `Fraction` | 有理数类，GCD 约分，加减乘除 |
| `gaussElimination` | 高斯-约当消元（RREF），列主元选取 |
| `renderMatrixGrid` | 动态矩阵网格渲染 |
| CSS | 响应式布局，触控优化 |
